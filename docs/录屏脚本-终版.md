# SciAgent 演示视频脚本（终版 · 分两段录）

> 用途：传智杯第九届作品提交第 7 项「演示视频地址」。
> 提交要求原文：**切勿提交百度网盘链接**，视频统一上传到 B 站、抖音等可公开访问的平台，
> 提交时只填视频链接（`https://...` 格式）。
> 建议传 B 站：1080p 可直传、可设封面与简介、审核快、链接长期有效。

总时长目标 **6 分 30 秒**（平台要求 5–8 分钟）。两段一次录完，中间不断。

---

## 一、录制前 10 分钟准备

### 1. 两个实例都要先起来

| 实例 | 地址 | 用途 | 关键配置 |
| --- | --- | --- | --- |
| 云端 | `https://sciagent.zp-avatar.cn`（备选 workbuddy 直链） | 第一段 | 包内 `.env` 已有 `EXPOSE_OFFLINE_SWITCH=0`，顶栏**不会**出现离线开关 |
| 本机 | `http://127.0.0.1:8013` | 第二段 | `.env` 保持 `EXPOSE_OFFLINE_SWITCH=1`、`OLLAMA_ENABLED=1` |

本机实例启动命令（在项目根）：

```bash
.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8013
```

启动后**先打开一次**，确认三件事：

1. `ollama list` 能看到 `sciagent-3b-v2-q8`，且双击过 `ollama app.exe` 让它常驻（后台进程会被系统回收）；
2. 顶栏能看到「云端 / 离线」开关，且默认停在「云端」；
3. 关掉代理（`https_proxy`），否则"断网"演示会被代理暴露。

### 2. 断网怎么断

- 优先：拔网线 / 关闭 Wi-Fi（最直观，录屏里能看到图标变化）。
- 备选：Windows 设置 → 网络 → 飞行模式。
- **先断网再切开关**，顺序反了会被误认为"切完就断了"。

### 3. 画面设置

- 分辨率 1920×1080，浏览器缩放 100%，隐藏书签栏（`Ctrl+Shift+B`）。
- 只开一个标签页，避免录到别的网站。
- 关掉微信/QQ 弹窗、关掉输入法候选窗。
- **不要打开** `deploy/.env`、`/admin` 的密钥页、任何含 API Key 的终端窗口。

### 4. 录屏软件

- OBS：输出 1080p / 30fps / MP4，码率 6000 kbps，录麦克风 + 系统声音（系统声音可关）。
- 或 Windows 自带 `Win+G`（够用，但码率偏低）。

## 三、第一段：云端 API 演示（0:00–5:05）

### 0:00–0:25 开场

**画面**：停在问答首页（不点任何按钮）。

**口播**：
> 这是 SciAgent，一个能自我校验引用的科研助手。它和普通 RAG 最大的区别有两条：
> 第一，模型只能引用真实检索到的片段，服务端会把片段换成 PDF 里的物理坐标，编不出坐标的引用直接判为幻觉并重新作答；
> 第二，同一份代码既能跑云端 API，也能完全断网跑本地模型。先用线上这个纯云端实例演示。

### 0:25–0:55 文献库与导入

**操作**：
1. 指一下左栏标题「文献库 39 篇」和顶栏的「文献 39 / 片段 27667」标签。
2. 点左栏 **「一键导入官方测试集（39 篇）」**。

**口播**：
> 库里有 39 篇论文、两万七千多个可定位片段、两千一百多个章节。点一键导入会走完整流水线：
> 解析、去重、切块、向量化、建章节树。判重的会跳过，并在结束后告诉我入库几篇、判重几篇、跟谁重复——
> 不会出现"导了 39 篇库里只有 36 篇"这种说不清的情况。

### 0:55–1:40 版面感知解析

**操作**：
1. 左栏点任意一篇（建议 *Attention Is All You Need*）。
2. 看中间页图 + 右侧 **「章节树」** 面板。
3. 点章节树里的某一节（如 3.1），观察右侧正文跳到该页并高亮 1 秒。
4. 用底部 **「上一页 / 下一页」** 翻两页，再用 `Ctrl + 滚轮` 缩放（或点顶部 `100%` 两侧的 −/+）。

**口播**：
> 解析是版面感知的：双栏阅读顺序会还原，章节树按字号层级和编号建出来，图、表、公式、参考文献分别成块。
> 点章节会直接跳到对应页；页面是连续滚动的，滚到页底自动进下一页，缩放支持按钮和 Ctrl+滚轮。

### 1:40–2:50 抗幻觉问答（核心，讲慢一点）

**操作**：
1. 在问答框输入：**「big 模型在 EN-DE 上的 BLEU 是多少？比此前最好结果高多少？」**，发送。
2. 指答案上方的「快速 / 深思」标记与耗时；指答案里的 `[1]`。
3. 点答案里的 `[1]` → 页面跳到原文该句并高亮；再点证据卡片，观察句级高亮（不是整段涂色）。
4. 在新对话里输入负例：**「这篇论文里提到的 Adam β3 参数的值是多少？」**
5. 指答案开头「文献中未提及」。

**口播**：
> 问一个数值题。答案第一句就是结论，28.4，比此前最好结果高 2 个点以上，并且每个结论后面带编号。
> 点编号会跳回原文那一句，高亮是**句级**的，不是把整段涂掉——服务端会在片段里挑出真正作答的那一句。
> 再看一个负例：论文里根本没有 β3 这个参数。它没有编，直接说未提及——这比答错更值钱。
> 右上角可以在快速和深思之间切，快速首字一秒三，深思多两秒多但会先推理一遍；这个开关只影响当次提问。

### 2:50–3:35 阅读器：双向引用与翻译

**操作**：
1. 翻到正文某页，点正文里的 `[11]` → 跳到 References 第 11 条并高亮；浮层里显示条目全文。
2. 在浮层里点「正文引用 N 处」里的一条 → 跳回原文该句。
3. 鼠标在英文正文上停 0.4 秒 → 出现悬停翻译浮层（整句）。
4. 选中一段英文 → 出现「译」按钮 → 点它。
5. 点顶部 **「中英对照」** 视图，左栏滚动，右栏跟着走。

**口播**：
> 引用是双向的：正文点 [11] 到第 11 条，条目浮层再点回去，按句高亮。
> 悬停 0.4 秒自动译整句，划词可以单独译一段，中英对照是双栏联动。

### 3:35–4:15 引用图谱与综述

**操作**：
1. 点顶栏 **「图谱」**（或图谱视图入口）。
2. 指节点数/边数、右侧「PageRank / 介数中心性 / 角色」。
3. 点 **「生成领域综述」**。
4. 切到 **Future Work**（未来研究方向）面板，指一条带「可能已涉及」的证据。

**口播**：
> 引用图谱是 221 条互引边，节点大小按 PageRank，还能看介数中心性和社区。
> 综述不是模型自由发挥，是按图谱影响力排序后生成，每条都带合法引用。
> Future Work 会把库里的开放问题抽出来，并用后续论文的方法原句去对撞，而不是拿关键词猜。

### 4:15–4:50 写作与可视化

**操作**：
1. 切到写作面板，点 **「论文框架」** → 输入一个 idea → 生成。
2. 指 References 全部来自库内（无编造）。
3. 点 **「架构图」** → 展示 mermaid/dot/tikz 四格式同构。
4. 点 **「数据图表」** → 选示例 CSV → 生成 → 指「Figure Caption」和数值回查。

**口播**：
> 写作有三块：论文框架、架构图、数据图表。框架的参考文献百分之百来自库内，没有一条编造。
> 架构图四种格式描述的是同一张图，图注里的数字会回查 CSV，对不上会被拦。

### 4:50–5:05 转折（关键的一句）

**操作**：切回问答首页，鼠标停在顶栏（云端实例这里没有离线开关）。

**口播**：
> 到这里都是云端 API 在跑。接下来我换到本地那个网址，把网断掉，
> 演示同一套界面、同一份代码，完全靠本机模型跑完的版本。

## 四、第二段：本地断网演示（5:05–6:30）

> 这段不用重复演示已经讲过的功能，只证明"断网也能跑，而且功能没变"。

### 5:05–5:25 断网 + 切开关

**操作**：
1. 切到本地实例标签页（`127.0.0.1:8013`），**先断网**（拔网线/关 Wi-Fi），让观众看到网络图标变化。
2. 指顶栏 **「云端 / 离线」** 开关，点它 → 变成「离线」。
3. 停留 2 秒，让画面显示切换成功提示。

**口播**：
> 网络已经断了。顶栏这个开关在云端实例上是看不到的——那里没有本地模型，摆一个永远灰着的按钮没有意义。
> 在本机实例上它可用。点一下，向量化、检索、重排、生成四段全部切到本机。

### 5:25–6:10 同一道题，本地跑一遍

**操作**：
1. 输入**与云端完全相同的问题**：「big 模型在 EN-DE 上的 BLEU 是多少？比此前最好结果高多少？」
2. 等答案出来（首次会含模型加载，约 15–20 秒；热态 6–8 秒）。
3. 指答案上方的模型名（`sciagent-3b-v2-q8`）与耗时。
4. 点答案里的 `[1]` → 证明锚点跳转在离线时同样可用。

**口播**：
> 同一道题。注意这里跑的是本机 3B，模型名和耗时都写在答案上方，不是挂个云端模型的名。
> 答案依然是 28.4，引用依然能点回原文——因为检索、锚点、校验这套逻辑跟云端是同一份代码，只是换了两套向量和本地生成。
> 召回会从 95% 掉到 89%，重排退化成规则打分，翻译质量也会降，这是真实的边界。

### 6:10–6:30 收尾

**操作**：停留首页，画面不切。

**口播**：
> 代码在 GitHub 上公开，同一份仓库两种形态，差别只有一个环境变量。
> 离线模式下搜索下载和新论文推荐不可用，因为那两个功能本质上需要外网，这个取舍写在文档里。
> 谢谢观看。

## 五、录制时的九个坑

1. **先在云端实例确认没有离线开关**。如果还能看到，说明包里的 `EXPOSE_OFFLINE_SWITCH` 没生效，别急着录。
2. **断网前先热一次本地模型**（在断网前问一题），否则录到的是"加载中"空等 15 秒。热过之后录出来是 6–8 秒。
3. **别在录屏里点「控制台」**（`/admin`），那里有口令页和参数页，容易带出敏感项。
4. **不要出现 `.env`、终端里的 Key、网盘链接**。提交要求明确禁止把视频放网盘。
5. **判重弹窗别乱点**：上传重复件会弹三选一，录屏里如果弹出，选「保留库中」并说一句"检测到重复版本"，反而加分。
6. **图谱和综述需要等**：生成领域综述约 5–10 秒，剪辑时可以加速，但不要剪掉"正在生成"的过程。
7. **口播不要念参数**，说人话；数字留给字幕。字幕建议后期加，B 站可自动识别再校对。
8. **一次录完**，中间念错就停 2 秒重念，后期剪掉；分段录会出现时间戳跳变（评委看得出）。
9. **上传 B 站时**：标题写「SciAgent · 能自我校验引用的科研智能体（云端 + 断网本地双模式）」，
   简介里放 GitHub 链接和"本视频含两段：云端演示 0:00–5:05，断网本地演示 5:05 起"，方便评委跳着看。
