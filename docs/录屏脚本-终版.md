# SciAgent 演示视频脚本（v59 · 分两段录）

> 用于提交第 7 项「演示视频地址」。界面对应 **v59**（2026-11-17），线上与本地同一版本。
> 总时长目标 **6 分 30 秒**（平台要求 5–8 分钟）。两段一次录完，中间不断。
> 提交要求原文：**切勿提交百度网盘链接**，视频统一上传 B 站等可公开访问的平台，只填 `https://` 页面地址。

## 一、开录前 15 分钟准备（逐条过）

### 1. 两个实例都先打开一次

| 实例 | 地址 | 用途 | 顶栏应该长什么样 |
| --- | --- | --- | --- |
| 云端 | `https://sciagent.zp-avatar.cn` | 第一段 | 只有一个模型名徽标，**没有**「云端 / 本地 3B」按钮 |
| 本机 | `http://127.0.0.1:8013` | 第二段 | 有「云端 / 本地 3B」两个按钮，默认停在「云端」 |

先各开一次的原因：云端沙箱睡过之后首个请求要等 20 秒，录进去就成了"卡住了"。

### 2. 本机三件事必须确认

```bash
# ① Ollama 在跑
curl -s --noproxy '*' http://127.0.0.1:11434/api/tags | head -c 200
# 应看到 sciagent-3b-v2-q8:latest

# ② 本地服务在跑
curl -s --noproxy '*' -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8013/
# 应为 200
```

③ 打开 `http://127.0.0.1:8013`，看顶栏「本地 3B」**不是灰的**。灰的说明 Ollama 没起，
双击 `C:\Users\User\AppData\Local\Programs\Ollama\ollama app.exe`，等 10 秒再刷新。

### 3. 断网怎么断

- 优先：关 Wi-Fi / 拔网线（画面里能看到图标变化，最有说服力）
- 备选：飞行模式

### 4. 画面

- 1920×1080，浏览器缩放 100%，`Ctrl+Shift+B` 隐藏书签栏
- 只开这一个标签页，关掉微信/QQ 弹窗与输入法候选窗
- **不要打开** `/admin` 控制台、`deploy/.env`、任何含 API Key 的终端

### 5. 录屏

OBS：1080p / 30fps / MP4 / 6000 kbps，录麦克风。或 `Win+G`。

## 三、第一段：云端（0:00–4:50）

### 0:00–0:20 开场

**画面**：停在问答首页，什么都别点。

**口播**：
> 这是 SciAgent，一个能自我校验引用的科研助手。
> 两条和普通 RAG 不一样：一是模型只能引用检索到的真实片段，服务端把片段换成 PDF 里的物理坐标，编不出坐标的引用会被判为幻觉；二是同一份代码既能跑云端，也能完全断网跑本地模型。
> 先看线上这个纯云端实例。

### 0:20–0:50 文献库

**操作**：指左栏「文献库 39 篇」→ 指顶栏「文献 39 / 片段 27667」→ 点 **「一键导入官方测试集（39 篇）」**。

**口播**：
> 库里 39 篇论文、两万七千多个可定位片段。一键导入走完整流水线：解析、去重、切块、向量化、建章节树。
> 判重的会跳过，结束后告诉我入库几篇、判重几篇、跟谁重复——不会出现"导了 39 篇只有 36 篇"这种说不清的情况。

### 0:50–2:10 问答（核心，讲慢一点）

#### ① 确定性作者题（0:50–1:15）

**操作**：左栏点 **Attention Is All You Need** → 问答框输入：

> 论文 Attention Is All You Need 的第 6 作者是谁，在哪个公司/机构工作？

**口播**：
> 先问一个作者题。答案几乎是瞬间出来的——因为这类问题它不去检索正文，直接读解析阶段存下的署名顺序。
> 让模型对着切块数人名必然数错，所以这条路径是故意绕开模型的。

#### ② GPU 题 + 证据跳转（1:15–1:55）

**操作**：输入

> 这篇论文训练 Base 模型用了多少块 GPU？什么型号？

→ 答案出来后点答案里的 `[1]` → 页面跳到原文该句 → 再点右侧证据卡片。

**口播**：
> 换一个需要跨段落找的问题。答案是 8 块 P100，后面带编号。
> 点编号跳回原文那一句，高亮是**句级**的，不是把整段涂掉——服务端会在片段里挑出真正作答的那一句。
> 右侧每条证据都有页码和锚点，可以逐条核对。

#### ③ 负例拒答（1:55–2:10）

**操作**：输入

> 这篇论文里 Adam 优化器的 β3 参数取了多少？

**口播**：
> 再看负例。Adam 只有 β1 和 β2，没有 β3。它没有编，直接说未提及。
> 这条比答对更值钱：系统宁可说不知道，也不给一个像样的假答案。

### 2:10–2:55 阅读与翻译

**操作**：
1. 翻到正文某页，点正文里的 `[1]` → 跳到 References 第 1 条
2. 在条目浮层里点「正文引用 N 处」的一条 → 跳回原文
3. 打开工具条 **「悬停译」** 开关 → 鼠标在英文句上停一下
4. 选中一段英文 → 出现「译」按钮 → 点它
5. 点视图 **「对照」** → 左侧滚动，右侧跟着走

**口播**：
> 引用是双向的：正文点 [1] 到参考文献，从参考文献还能点回正文被引的那一句。
> 悬停 0.4 秒译整句，划词可以单独译一段，中英对照是双栏联动。

### 2:55–3:50 图谱（这段刚改过，重点）

**操作**：
1. 点视图 **「图谱」**
2. 指顶部统计「39 篇 · 213 条互引边 · 参考文献 3679 条，命中库内 243 条」
3. 点 **「选择文献（39/39）」** → 点 **「清空」** → 勾 5 篇（建议 Attention / BERT / GPT-3 / Layer Normalization / FlashAttention）→ 点 **「按所选重建图谱」**
4. 指图上每个圈都有名字 → 点其中一个节点，看右侧「被这 N 篇引用 / 引用了这 N 篇」
5. 点 **「生成领域综述」**
6. 关掉综述，点 **「未来工作方向」** → 指一条标着「可能已被后续工作触及」的

**口播**：
> 引用图谱默认 39 篇、213 条互引边，节点大小按 PageRank。
> 这里可以挑文献：勾哪几篇就只用哪几篇建图。注意它不是把别的点藏起来——PageRank、介数、基石和桥接的判定都在选中的这几篇里重新算，所以"这 5 篇里谁是基石"是个真结论，不是全库排名的裁剪。
> 选 5 篇之后每个节点都带名字，点一个能看到它引了谁、被谁引。
> 综述不是模型自由发挥，是按图谱影响力排序生成的，每条都带合法引用。
> 未来工作方向是从各篇的 Future Work 和 Limitations 里抽的原句，再用库内较新论文的方法原句去对撞，被后来者做过的会被标出来——避免给你一个早就有人做掉的 idea。

### 3:50–4:35 写作

**操作**：
1. 视图 **「写作」** → **「论文框架」** → 输入 idea（示例：`把证据链做成可审计的引用校验层`）→ 生成
2. 指 References 全是库内文献
3. 切 **「架构图」** → 指 mermaid / dot / tikz / matplotlib 四份代码
4. 切 **「数据图表」** → 生成 → 指 Figure Caption 与数值回查

**口播**：
> 写作三块：论文框架、架构图、数据图表。
> 框架的参考文献百分之百来自库内，编造的条目在结构上产生不了。
> 架构图一次生成四种格式，描述的是同一张图。图注里的数字会回查原始数据，对不上会被拦。

### 4:35–4:50 转折

**操作**：切回问答首页，别关标签页。

**口播**：
> 到这里都是云端在跑。接下来换到本地那个网址，把网断掉，演示同一套界面、同一份代码，完全靠本机模型跑完。

## 四、第二段：本地断网（4:50–6:30）

### 4:50–5:15 断网 + 切本地

**操作**：
1. 切到本地标签页（`127.0.0.1:8013`）
2. **断网**（关 Wi-Fi），让画面看到网络图标变化，停 2 秒
3. 点顶栏 **「本地 3B」** → 等提示出现

**口播**：
> 网络已经断了。注意这个「云端 / 本地 3B」的切换在云端实例上看不到——那边没有本地模型，摆一个永远点不动的按钮没有意义。
> 在本机实例上它可用。点一下，向量化、检索、重排、生成四段全部切到本机。

### 5:15–6:05 同一道题，本地跑一遍

**操作**：问**与云端完全相同**那道 GPU 题，等答案（首次含模型加载 15–20 秒；热态 6–8 秒）；出来后在答案上方指模型名 `sciagent-3b-v2-q8`；点 `[1]` 证明锚点跳转离线也可用。

**口播**：
> 同一道题，8 块 P100。跑的是本机 3B，模型名和耗时都写在答案上方，不是挂个云端模型的名字。
> 引用依然能点回原文——因为检索、锚点、校验跟云端是同一份代码，只是换了一套本地向量和本地生成。
> 边界也说清楚：离线召回从 95% 掉到 89%，重排退化成规则打分，翻译质量会降，搜索和新论文推荐在离线时不可用。这些取舍都写在文档里。

### 6:05–6:30 收尾

**画面**：停在首页。

**口播**：
> 代码在 GitHub 上公开，同一份仓库两种形态，差别只有一个环境变量。
> 谢谢观看。

## 六、录制时的十个坑

1. **云端顶栏不该有「云端 / 本地 3B」**。出现说明包配置错了，别录。
2. **先热一次本地模型**（断网前问一题），否则录到的是 15 秒空等。
3. **断网后「本地 3B」点不动**：刷新页面再点。10 秒缓存里可能存了旧的探测结果。
4. **别点「控制台」**（`/admin`），有口令页与参数页。
5. **画面里不能出现** `.env`、API Key、网盘链接。
6. **图谱那段别全选 39 篇讲标签**——39 个名字一定互相压。按脚本先清空再选 5 篇。
7. **综述和未来工作要等 3–6 秒**，后期可加速，但别剪掉"正在生成"。
8. **口播不要念参数**，说人话；数字留给字幕。
9. **一次录完**，念错停 2 秒重念，后期剪，别分段录。
10. **上传 B 站**：标题「SciAgent · 能自我校验引用的科研智能体（云端 + 断网本地双模式）」，
    简介放 GitHub 链接 + "云端 0:00–4:50，断网本地 4:50 起"。
