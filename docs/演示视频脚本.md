# SciAgent 演示视频脚本（5–8 分钟）

> 目标：让评委在 8 分钟内看到三件别人不容易做到的事——**答案能点回原文**、
> **表格/公式这类"PDF 里最难读的东西"能答对**、**从读到写是一条闭环**。
> 录制环境：本机 `http://127.0.0.1:8013`（比公网快，等待短）；窗口 1680×1050，浏览器缩放 100%。
> 备选：公网 `https://sciagent-research.app.workbuddy.host/?sharecode=CHBCOXLVVO`（首次会唤醒，冷启动 10–30 秒，**建议先点开预热再录**）。

## 录制前 3 分钟准备

1. 关掉微信/QQ/钉钉通知，退出全屏聊天窗口
2. 浏览器只留一个标签页，地址栏清空（避免露出本地路径）
3. 打开页面 → 等右上角出现「文献 38 篇 · 块 19970」（说明索引热了）
4. 后台先别登（第 6 段再登，避免口令出现在画面）
5. 麦克风试一句，确认没有爆音

## 三个必须录到的"硬证据"

1. **答案 → 引用 → 原文**：同一个 [n] 从答案跳到 PDF 那一页，这是抗幻觉最直观的证明
2. **表格题答对**：复杂度、BLEU 这类"只能看表"的问题，普通 RAG 经常答"未提及"
3. **证据不足时说不知道**：GPT-5 参数量 → 明确说库里没有

## 常见翻车点

- **问复杂度不带论文名** → 可能命中别的论文，答案不对。一定说「Transformer 论文里」
- **页面没热就开录** → 第一题会等 20 秒以上。先点一次示例问题预热
- **公网录制** → 首次访问冷启动 10–30 秒，且模型调用比本地慢一倍，尽量用本地
- **窗口太小** → 1680×1050 以下，右侧证据卡会被挤掉，录不到引用

## 剪辑建议

- 等待模型回答的 8–20 秒：**1.5 倍速**，保留首尾各 1 秒，中间加速
- 架构图/图表生成同理
- 不要加背景音乐盖住讲解；不要加花哨转场，评委看的是内容
- 导出：MP4 / H.264 / 1920×1080 / 30fps，文件名 `SciAgent-演示视频-章璞.mp4`
