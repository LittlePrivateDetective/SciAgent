# DeepSeek 开思考 / 关思考：30 题对照测评

> 2026-11-12 · 模型 `deepseek-v4.1-flash` · 60 次调用 · 原始数据 `docs/qa/evidence/thinking_ab_result.json`

## 一、怎么测的

三件事决定了这套测法有没有意义，先说清楚：

**① 证据冻结。** 不走 `/api/chat`——那个接口里混了检索、重排、校验、反思四个节点，耗时和答案都会被别的东西影响。这里先把 30 道题各自的 top-8 证据检索出来存成 JSON，两个模式喂**逐字节相同**的 prompt，只切 `enable_thinking`。

**② 题目覆盖五种能力**，不是随便挑几道：

| 类别 | 题数 | 考什么 |
|---|---:|---|
| A 事实抽取 | 8 | 答案在证据里明写，看能不能抄对 |
| B 数值超参 | 6 | `d_model=512`、`W=4096` 这类，最容易看出编造 |
| C 跨文献对比 | 5 | 要把两份证据的差异组织起来 |
| D 证据不足 | 5 | 论文里根本没写（作者邮箱、显卡数量），**正确行为是拒答** |
| E 结构化输出 | 6 | 给定 schema 的 JSON |

**③ 只用机器能核的量打分**：引用编号是否越界、答案里的数字是否都在证据原文里、是否明确拒答、JSON 能否解析。不做"看起来好不好"的主观评分——那种分数换个评委就变。

**判定口径的一个坑**（已修）：第一版把 `[11]` 里的 `11`、`arXiv:2212.04356` 整串都判成"证据里没有的数字"，得出"开思考 3 次幻觉、关思考 1 次"的错误结论。剔掉引用标记和 arXiv 形式后，**两边都是 0**。

## 二、总体

| 指标 | 开思考 | 关思考 | 变化 |
|---|---:|---:|---:|
| 平均耗时 | 3418 ms | **1593 ms** | −53% |
| 中位耗时 | 2703 ms | **1503 ms** | −44% |
| 单题最慢 | 12.4 s（A8） | 3.0 s（C5） | −76% |
| 平均输出 token | 434 | **128** | −70% |
| 其中思维链 | 268 | 0 | — |
| 平均答案字数 | 316 | 235 | −26% |
| JSON 可解析 | 100% | 100% | 持平 |
| **引用越界次数** | **0** | 2 | 关思考更差 |
| **数字不在证据里** | 0 | 0 | 持平 |
| **证据不足时正确拒答** | 4/5 | **5/5** | 关思考更好 |
| 有答案的题真的答了 | 14/19 | 14/19 | 持平 |

两个反直觉的结果值得单独说：

- **关思考不会更爱编数字。** 直觉是"想得少就容易瞎写"，实测两边都是 0。因为提示词已经把"数字必须原样抄"写成硬规则，这跟想不想没关系。
- **关思考的引用更容易越界。** 2 次 vs 0 次。它在 B2 里引了 `[9]`，而那条题只给了 8 条证据——没经过"先数一遍证据有编号几"的思考，编号就凭空长出来了。

| 类别 | 开思考 耗时 / 正文token | 关思考 耗时 / 正文token |
|---|---|---|
| 事实抽取 | 3666 ms / 499 | 1459 ms / 105 |
| 数值超参 | 2296 ms / 235 | 1525 ms / 124 |
| 跨文献对比 | 4056 ms / 537 | 2306 ms / 203 |
| 证据不足 | 2657 ms / 298 | 1675 ms / 145 |

**结构化输出差得最狠**（3.7 倍）。原因很直接：思维链对"按 schema 填字段"没有任何帮助，纯属开销。**数值超参差得最少**（1.5 倍）——这类题思考本来就不长，看一眼证据就能抄。

## 四、五个具体差别（附原答案）

### 1. 概念区分：开思考明显更强

问：*Mistral 7B 的上下文窗口长度是多少？*

- **开思考**：`证据未给出以「上下文窗口长度」为名的单一数值，只给出滑动窗口注意力（SWA）的窗口大小 W = 4096：在最后一层，理论 attention span 约为 131K tokens……`
- **关思考**：`Mistral 7B 的滑动窗口注意力（SWA）窗口大小 W = 4096，在最后一层理论注意力跨度约为 131K tokens；证据未直接给出模型部署时的上下文窗口长度数值。`

两边都提到了 W=4096，但**开思考先划清"滑动窗口 ≠ 上下文窗口"**，再给数；关思考把两个概念摆在一起，读者容易误以为上下文就是 4096。这类概念辨析题，思维链的价值最大。

### 2. 指令遵循：开思考更守格式

问：*Transformer 的编码器和解码器各由多少层堆叠而成？*

- **开思考**（218 字）：先给结论 `N = 6`，再分两点给依据（编码器每层两个子层、解码器多一个子层），每点带引用。
- **关思考**（26 字）：`编码器和解码器各由 N = 6 个相同的层堆叠而成。`

答案**是对的**，但 prompt 里明确要求"结论后面用 1-3 个要点给依据"，它没照做。关思考时模型倾向于"最短路径作答"，格式约束经常被跳过。

### 3. 不确定性表达：开思考会把"缺什么"说出来

结构化题 E4（要求输出 `{method, dataset, metric, value}`）：

- **开思考**：`{"method": "pass@k", "dataset": "HumanEval", "metric": "pass@k", "value": "文献中未提及"}`
- **关思考**：`{"method": "", "dataset": "", "metric": "", "value": ""}`

开思考知道在缺值的位置写"文献中未提及"，关思考直接交白卷。对"可追溯"这个卖点来说，前者明显更有用。

### 4. 拒答：开思考"愿意给"，在这类题上是缺点

问：*LLaMA 论文的致谢部分感谢了哪些人？*（证据里只有 Llama 2 / Llama 3 的致谢）

- **开思考**（427 字，**未拒答**）：一上来就是 `证据中可见的致谢名单出自 2307.09288（Llama 2）第47页：Armand Joulin、Edouard Grave、Guillaume Lample……`，接着把 Llama 2 的 11 个人名和 Llama 3 的 9 个人名都列了出来。它没有说"这不是你要的那篇"。
- **关思考**（652 字，**拒答**）：第一句就是 `证据中未提及 LLaMA 论文致谢部分感谢的具体人员名单`，然后才解释"现有证据里是 Llama 2/3 的致谢"，附上引用。

用户问的是 LLaMA 1，开思考给出的是另外两篇的名单——**信息很足，但不是答案**，还容易被当成答案抄走。关思考先划边界再补充，读起来啰嗦，行为是对的。这也是 D 类拒答 4/5 vs 5/5 的唯一一题差异。

### 5. 引用规范：唯一开思考全胜的硬指标

30 道题里，开思考引用越界 **0** 次，关思考 **2** 次（都在 B2：那条题给了 10 条证据，它引了 `[11]` 和 `[18]`）。差别不在"想不想"，而在**开思考会先清点一遍证据编号再落笔**。

## 五、结论

**思维链买到的不是"更全"，是"更准"**：概念辨析（滑动窗口 vs 上下文）、格式遵循（给依据还是只给结论）、不确定性表达（写"未提及"还是交白卷）、引用编号规范。它在"答案更长"上是副产品。

**关思考买到的是时间和钱**：快 53%、输出 token 少 70%。在 30 题里，答案正确率并没有下降（14/19 对 14/19），也没有变得更爱编数字。

### 怎么用

| 场景 | 建议 | 理由 |
|---|---|---|
| 现场演示、随手问答 | **关** | 1.6 秒 vs 3.4 秒，差一倍；观众不等 |
| 概念辨析题（"A 和 B 有什么区别""这个数到底指什么"） | **开** | 第四节第 1 条：它会把概念边界先划清 |
| 需要严格引用、要落到具体页 | **开** | 引用越界 0 vs 2 |
| 结构化抽取（填 JSON / 图注 / 表格） | **关** | 差 3.7 倍，思考对填字段没帮助 |
| 明确知道证据不足、要它老实说 | **关** | 开思考会"顺手多给"，反而越界 |

默认值维持 `LLM_THINKING=0`（上一轮定的），因为这个项目的演示场景是"问一句、马上要答案"。要开的时候后台一键切，不用重启。

## 七、局限

1. **单次采样**，`temperature=0.2`。同一题换个时间跑，答案会变；表里的差异是"这 30 题这一次"的结果，不是分布。
2. **判定靠正则**：引用越界和数字比对都能机器核，但"答案对不对"没做人工标注，只有"有没有给实质答案"这种粗判。第四节那五条是我逐条读出来的，不是自动打分。
3. **证据是冻结的 top-8**，所以这套测法测的是"给定证据时模型的表现"，不包含检索波动——那是另一件事（见缺陷表 D-67）。
