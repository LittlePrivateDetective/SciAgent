# 自测清单（提交前手工验证）

> 目的：在录视频、打最终包之前，自己把每个模块走一遍。
> 机器能测的已经在 `tests/` 里跑过了（40 条回归 + 40 条单测 + 47 项接口巡检 +
> 参数生效 17 项 + 图谱交互 7 项 + 写作分步 4 项），这份清单只列**必须人眼判断**的。
> 行尾标「自动」的，说明那条已经有脚本覆盖，人眼只需抽查一下观感。
>
> 环境：本机 `http://127.0.0.1:8013`（快）／云端 `https://sciagent-research.app.workbuddy.host/?sharecode=CHBCOXLVVO`（真）
> 后台：`/admin`，口令在 `.env` 的 `ADMIN_PASSWORD`

## 怎么用

1. **每轮只测一个模块**，别一次全点，否则出错记不清是哪一步
2. 每条都要看「预期」，不符就记到最后一节的表里（**症状 + 你当时点了什么**，不用写原因）
3. 同一处连续失败 2 次就停手记下来，别反复重试——很多问题是状态被前一次操作带脏的
