# 纯本地模式（完全断网）

> 一个开关切换两条链路：云端（默认）和纯本地。同一份代码，不改配置重启也不用换分支。
> 入口在顶栏最左边那个「云端 / 离线」胶囊开关。

---

## 它到底换了什么

| 环节 | 云端模式 | 纯本地模式 |
|---|---|---|
| 查询向量化 | 远程 qwen3.7-text-embedding（约 420 ms） | 本机 bge-m3（热态约 100 ms） |
| 向量检索 | 读 `chunks.embedding` | 读 `chunks.embedding_local` |
| 重排 | 远程 cross-encoder（约 430 ms） | **不发请求**，退回关键词覆盖率 + 位置先验 |
| 生成 | DeepSeek（云端） | 本机 `sciagent-3b-v2-q8`（Ollama） |
| 搜索下载 / 新论文推荐 | 可用 | **不可用**（本质上需要外网） |

两套向量**同维（1024）但语义空间不同**，所以必须分列存、各读各的，绝不能混用——
混用不会报错，只会悄悄降低召回。

---

## 已实测的数字

向量召回（19 道有标准答案的题，文档级 recall@10）：

| 向量模型 | 召回@10 | MRR@10 | 单次查询耗时 |
|---|---|---|---|
| 云端 qwen3.7-text-embedding | 95% | 0.789 | 约 420 ms（网络） |
| **本机 bge-m3** | **89%** | **0.661** | **约 100 ms（CPU 热态）** |
| 本机 bge-small-zh（试过，不可用） | 58% | 0.190 | 约 20 ms |

> bge-small-zh 不能用的原因：它按"语言"匹配而不是"语义"。库里 36 篇是英文、
> 提问是中文，它会把中文期刊论文排到最前面。bge-m3 多语种，这个问题不存在
> （同一问题中英两句话的向量相似度 0.897）。

端到端问答（同一道题、限定单篇）：

| 模式 | 模型 | 耗时 | 答案 |
|---|---|---|---|
| 云端 | deepseek-v4.1-flash | 4.5 s | 正确 |
| 纯本地（首次） | sciagent-3b-v2-q8 | 29.5 s | 正确（含 14 s 模型加载） |
| **纯本地（热态）** | sciagent-3b-v2-q8 | **6.5 s** | 正确 |

## 怎么开

### 一次性准备（只需做一次）

```bash
# 1. 装推理依赖（云版不需要，见 requirements-offline.txt）
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install transformers

# 2. 下载 bge-m3（2.27 GB），放到 .env 的 EMB_LOCAL_MODEL 指向的位置
#    默认 D:/models/models/bge-m3

# 3. 为全部 chunk 算一份本地向量（GPU 上约 19 分钟；中途断了可以重跑，会接着来）
ml/.venv/Scripts/python.exe scripts/build_local_vectors.py
```

`chunks` 表新增了 `embedding_local` 列，所以**云版的向量完全不受影响**，
随时能切回去。

### 每次切换

点顶栏的「云端 / 离线」开关即可。切换会：

- 校验三件事（本地向量是否齐、模型文件是否在、Ollama 是否可用），缺一样就拒绝切换并说明原因
- 清两层缓存（向量库内存缓存、查询向量缓存）——不清会让切换后的第一次检索拿到错误向量
- 落盘到 `app_settings`，重启后保持上次的模式

## 现在的局限

1. **召回 89% vs 云端 95%**。19 题里有 2 题掉召回（"只有一张 6GB 显卡做微调该参考哪篇"
   这类需要语义推断的题）。这是向量模型本身的差距，不是配置问题。
2. **重排退化成规则打分**。离线时不发请求，对比类问题（"A 和 B 有什么区别"）
   的证据排序会比云端差一些。想补可以再上一个本地 cross-encoder（另加 570 MB）。
3. **首次问答慢 25 秒左右**。bge-m3 在 CPU 上加载约 14 秒，只发生一次。
4. **搜索下载、新论文推荐不可用**。这两个功能要访问 arXiv 和外部源，离线做不了。
5. **翻译质量下降**。翻译跟生成走同一个路由，离线时由 3B 来做，长段落明显不如云端。

## 排障

| 现象 | 原因 |
|---|---|
| 开关是灰的，悬停说"本地向量未就绪" | `scripts/build_local_vectors.py` 没跑完，或只跑了一部分 |
| 开关是灰的，悬停说"本机 Ollama 不可用" | Ollama 没启动。双击 Ollama 桌面应用 |
| 切换后问答报"文献未提及"变多 | 正常，离线重排退化 + 召回差几个点 |
| 想彻底断网验证 | 关掉网卡后切离线模式，问答应仍然可用（搜索/推荐会报错，属预期） |
| 想切回去 | 再点一次开关，或 `POST /api/system/mode {"mode":"cloud"}` |
